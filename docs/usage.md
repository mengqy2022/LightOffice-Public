# 轻舟使用说明

适用版本：0.5.1.0，Windows 10/11，.NET Framework 4.8。

## 启动和桌面设置

解压正式 ZIP 后运行 `LightOffice.exe`。程序在托盘常驻；单击选中文件会显示对应工具花屿，托盘双击或 `Ctrl+Alt+Space` 可手动呼出。

托盘或花屿右键菜单提供：

- 「桌面与自动展开 → 开机时启动轻舟」：开启后在当前用户登录 Windows 时启动，无需管理员权限。移动程序目录前请关闭此开关，在新目录运行后重新开启；删除程序前也应先关闭。Windows 的“启动应用”设置需允许轻舟启动。
- 「保持紧凑花屿」：开启后手动呼出也保持紧凑，鼠标悬停不再放大；点击分类仍可展开操作，再点同一分类回到紧凑形态。
- 「花屿大小（紧凑 / 展开）」：小巧、标准、清晰分别使用 140、150、170 DIP 的紧凑直径，展开直径按比例变化。设置即时应用并保存；已收起的小花心保留 56 DIP。

## 截图、文字识别和翻译

1. 从托盘或「全部工具 → 截图」进入截图工作台，框选屏幕区域，也可使用「选窗口」或「全屏」。
2. 在截图工具栏选择「简体中文」「英语」或「系统首选语言」，点击「文字识别」。OCR 使用 Windows 本地能力，不上传截图，也不需要额外捆绑 OCR 引擎。所选 OCR 语言包必须已经安装；缺少时按提示前往 Windows 语言选项安装。
3. 识别结果可编辑和复制。调整选区、修改标注或重新截图后，旧识别结果会清空，需重新识别。截图上的原始图像和文件不会因 OCR 改动。
4. 选择译为中文或英语，点击「翻译 ↗」打开 Google 翻译网页。没有文字时先执行识别；成功打开浏览器后结束截图覆盖层。网页翻译需能访问 Google，会向该服务发送结果框中的文本，不传截图。最多传递 4000 字符，较长内容请分段复制。此版本不提供应用内离线翻译。

识别准确率受字体、画面清晰度和语言影响，结果应人工核对。系统 OCR 对图片边长有限制，超过时请缩小选区。高分屏截图还适用软件的 1600 万像素交互边界。

## 可选功能与数据处理

基础包不捆绑 LibreOffice、7-Zip、Bandizip、Python、R 或翻译模型。文档转 PDF 可选择本机安装的 LibreOffice 或 Microsoft Office；外部组件通过托盘「可选组件」管理。

「数据科学」处理 CSV/TSV，可筛选、清理、去重、按列汇总、按行合并和绘制汇总图。大文件逐记录读取，但去重和分组状态受预算限制；当前没有 XLSX 结构化导入和编辑。
