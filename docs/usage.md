## 启动和桌面设置

安装器在当前用户目录 `%LOCALAPPDATA%\Programs\LightOffice\0.6.0.0` 安装并创建快捷方式，无需管理员权限；也可解压正式 ZIP 后运行 `LightOffice.exe`。保留同目录 DLL、配置和许可。程序在托盘常驻；单击选中文件会显示对应工具花屿，托盘双击或 `Ctrl+Alt+Space` 可手动呼出。

托盘或花屿右键菜单提供：

- 「桌面与自动展开 → 开机时启动轻舟」：开启后在当前用户登录 Windows 时启动，无需管理员权限。移动程序目录前请关闭此开关，在新目录运行后重新开启；删除程序前也应先关闭。Windows 的“启动应用”设置需允许轻舟启动。
- 「保持紧凑花屿」：开启后手动呼出也保持紧凑，鼠标悬停不再放大；点击分类仍可展开操作，再点同一分类回到紧凑形态。
- 「花屿大小（紧凑 / 展开 / 小花心）」：小巧、标准、清晰分别使用 140、150、170 DIP 的紧凑直径，展开直径按比例变化。设置即时应用并保存；已收起的小花心也会按档位同比缩放。

展开花屿右上角有当前会话的「置顶 / 已置顶」，多开入口移至左下方，右上角保留收起和关闭。分类操作区使用叶片轮廓，常用项优先补齐当前分类功能，最多九项。花屿右键菜单和托盘都提供「花屿始终置顶」，设置会保存。各功能工作台右上角提供「置顶 / 已置顶」和「×」，按住标题可移动窗口；工作台置顶仅作用于当前窗口。数据科学、图表、按行合并、可选组件与图片/PDF 等工作台使用相同的圆角卡片和标题栏操作。

## 截图文字识别和翻译

默认 `Ctrl+Alt+S` 截图；截图内 `Ctrl+Shift+O` 识别、`Ctrl+Shift+T` 翻译。托盘和截图页都可配置快捷键，重复或系统注册冲突会提示。

1. 从托盘或「全部工具 → 截图」进入截图工作台，框选屏幕区域，也可使用「选窗口」或「全屏」。
2. 在截图工具栏选择「简体中文」「英语」或「系统首选语言」，点击「文字识别」。OCR 使用 Windows 本地能力，不上传截图，也不需要额外捆绑 OCR 引擎。所选 OCR 语言包必须已经安装；缺少时按提示前往 Windows 语言选项安装。
3. 识别结果可编辑和复制。调整选区、修改标注或重新截图后，旧识别结果会清空，需重新识别。截图上的原始图像和文件不会因 OCR 改动。
4. 选择「英 → 中」或「中 → 英」，点击「翻译」。没有文字时先执行本地识别；原文与译文直接显示在轻舟内，可编辑原文、复制译文或取消翻译。调整选区、编辑原文或切换翻译方向会清除过期译文。
5. 在线翻译使用 MyMemory HTTPS API，点击翻译才发送结果框中的文字，不传截图，不打开浏览器。每次最多 4000 字符，自动按服务字节上限分段；单请求超时 15 秒、整次任务最多 60 秒。免费服务有额度及网络限制，失败时保留原文并显示原因，可稍后重试。此版本支持中英互译，未内置离线翻译模型。

识别准确率受字体、画面清晰度和语言影响，结果应人工核对。系统 OCR 对图片边长有限制，超过时请缩小选区。高分屏截图还适用软件的 1600 万像素交互边界。

## 可选功能与数据处理

基础包不捆绑 LibreOffice、7-Zip、Bandizip、Python、R 或翻译模型。文档转 PDF 可选择本机安装的 LibreOffice 或 Microsoft Office；外部组件通过托盘「可选组件」管理。

「数据科学」处理 CSV/TSV，可筛选、清理、去重、按列汇总、按行合并和绘制汇总图。大文件逐记录读取，但去重和分组状态受预算限制；当前没有 XLSX 结构化导入和编辑。

## 打开方式与 F2

默认打开跟随 Windows；常用次数只用于推荐，不自动改变默认。打开方式面板始终保留 Windows 默认入口，异步枚举系统推荐，自定义 EXE 另行添加（最多三个）。管理中明确选择「轻舟内优先」才覆盖当前文件在轻舟内的打开入口，选择「跟随 Windows」即可恢复。

「加入系统推荐」仅在当前用户范围追加候选，不改 Windows 默认关联和 UserChoice。原生菜单展示顺序及刷新由 Windows 决定。移除轻舟项只移除本地记录，不卸载程序、不删除其他软件关联；商店应用通过系统处理程序调用。

常驻进程处理 F2 时单独读取当前选择，不等待花屿显示防抖或缩略图。双击 / 拖动抑制仍保留；轻舟进程尚未运行时，F2 由 Windows 处理。

## 数据流程与数值图

「保存流程」记录版本化 JSON、列结构、编码和处理参数，不嵌入原文件路径或原始行；筛选词、替换值和列名仍可能包含业务信息，分享前需检查。载入时核对列名顺序及编码，先预览，再全量另存。

「数值绘图」支持直方图和散点图，扫描全文件后使用固定种子抽样，界面最多一千点。图中标明扫描 / 有效 / 空值行及样本数；非法非空数值报行号。直方图为样本等宽分箱，最后一箱含最大值，不能视为全量分布统计。可另存 PNG。

## 批量改名与恢复

添加 1–500 个文件，设置前后缀、保留原名或使用序号，先预览再执行。保留扩展名；不覆盖、拒绝同名与重复目标。执行前保存内容哈希和恢复记录，部分失败 / 取消保留已完成项，同步对应花屿与历史路径。

从记录恢复会校验内容和原名称占用，文件被外部修改时停止。记录含完整路径，请妥善保存。操作期间其他相关工作台需先关闭。

## 水印与高级解压

图片 / PDF 水印支持文字、位置、透明度、字号及最多一百文件另存。长文字自动缩小以完整显示；图片输出 PNG。0.6 PDF 工作台显示水印位置预览，不显示原页面底图；0.7 候选增加可选的真实首页预览，仍需复核实际导出结果，见[组件专题](components.md)。

「移除轻舟水印」仅处理本软件添加且保留恢复标记的 PDF 水印，不自动删除其他水印，不处理扫描图内水印。PDF 加密、交互表单与数字签名文档暂不处理。

内置 ZIP 不需要引擎；配置 7-Zip 后支持普通 7z / RAR 解压，最多一万项、512 MiB 声明解压数据。拒绝加密、分卷、链接、附加数据流和不安全路径；逐项核对大小，全部成功后发布新目录。不创建 RAR。

## 更新与移除

先关闭工作台并从托盘退出旧版，再启动新版本。启用过登录自启的用户，应在旧版关闭，新目录运行后重新开启。相同版本安装目录已存在时仅校验，不覆盖不同内容。

0.6 安装器没有控制面板卸载项。移除前关闭自启、退出程序，再删除对应版本目录与桌面 / 开始菜单快捷方式。用户设置和已经导出的文件不会自动删除。0.7 候选安装版加入按版本卸载入口与剩余版本快捷方式回退，保留个人设置与可选组件，详见[候选说明](preview-0.7.md)。
