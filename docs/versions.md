# 版本对照与更新

[正式下载](../releases/README.md) · [更新记录](changelog.md) · [0.7 详情](preview-0.7.md)

截至 2026-11-12，当前版本为 **0.7.5.1**。新增纸墨主题、透明文件夹预览、母子花心和组配色，修复预览重复关闭异常并支持Inno跨版本安装更新。保留截图画笔、Enter 复制并完成、小屏高缩放补强、首次引导、真实 CSV 实操、紧凑快捷键提示、完成关闭和关于反馈；保留混淆与完整安装向导，无新增运行引擎。见[操作教学](getting-started.md)和[安装指南](installation.md)。

## 0.7.5.1 文件夹与安装差异

0.7.5.0为未公开本地候选；首次公开此系列使用0.7.5.1和完整标签v0.7.5.1。文件夹悬停、分层浏览、保留子花心和主题配色见[桌面指南](desktop.md)。新安装器启动即检查运行状态，识别Inno旧版后沿用原目录及卸载身份、跳过哈希一致文件、保留设置 / 组件，失败恢复；旧式安装器保持独立。完整下载，无差分下载；见[安装指南](installation.md)。

## 0.7.4 交互差异

首次手动启动可查看引导或进行六行 CSV 的筛选 / 另存练习。截图常用菜单操作时按使用习惯轻量提示快捷键，支持关闭；重命名及两类设置保存成功后自动关闭。PDF 工具改名为「移除已添加水印」，只移除本软件添加且保留恢复标记的水印。关于页提供 Mengqy / Codex / 实际版本、博客和邮箱。完整流程见[本版说明](getting-started.md)，测试边界见[验证范围](validation.md)。

## 更新步骤

1. 保存工作台结果并从托盘退出，确认不再处理任务。
2. 从公开 Release 下载新版本并核对校验值。便携版使用新的完整目录，保留全部 DLL / 配置 / 许可。
3. Inno原位更新保留已登记的自启。便携版或旧式安装改变路径时，先在旧版关闭自启，再在实际使用的新路径按需开启。确认“关于轻舟”为0.7.5.1。
4. 不同版本使用共享个人设置时，避免并发运行或同时写入；较旧版本未必理解新字段。没有提供设置自动降级的保证。
5. 原始文件、导出结果和改名恢复记录自行保留。不同版本的恢复操作应先使用测试副本验证。

已有同版本 0.7.2.0 本地候选安装目录时，先退出并备份设置 / 结果，卸载该候选后再安装正式包。正式版增加混淆，文件哈希与候选不同；安装器不会覆盖已存在但内容不同的同版本目录。便携用户可解压到新的完整目录使用。

## 卸载与回退

0.6：关闭自启、退出，删除对应程序目录和快捷方式；个人设置和导出文件不会随手动删除程序目录自动清理。

0.7.3 / 0.7.4历史安装按版本独立；0.7.5.1识别Inno旧版后原位更新，不再生成一个并列副本。每个实际安装保留卸载入口，卸载保留个人设置与可选组件。降级被拒绝，需回退时备份结果、正常卸载新程序，再完整安装旧版本；不要把旧文件覆盖进新安装目录。已有隔离解包 / 载荷验证，不等于干净机器 GUI 全矩阵验收。便携版仍可退出后手动移除。

回退前退出当前进程，再运行保留的旧版本完整目录。旧版不能识别新设置或流程时停止尝试，保留副本再反馈，不应通过随意删除设置解决问题。

程序及安装器当前未代码签名。正式渠道以 Release 资产及其 `.sha256` 为准，仓库的源码下载按钮不等于软件安装包。
