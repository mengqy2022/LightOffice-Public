# 常见问题与边界

版本说明：正式下载为 0.6.0.0；0.7.2.0 为本地候选，新增能力见[候选说明](preview-0.7.md)。完整操作可从[全功能导航](catalog.md)进入。

**没有 Microsoft Office 能用吗？** 图片、PDF、ZIP、截图和 CSV 数据功能可独立使用。办公文档转 PDF 可另外配置 LibreOffice；不必为了基础功能安装它。

**是否内嵌庞大的运行环境？** 基础包使用系统 .NET Framework 4.8，不捆绑浏览器、LibreOffice、Python、R 或大型模型。可选组件另外配置；包体和运行内存是不同指标，图片尺寸、数据状态和引擎子进程会影响内存。

**500 MB、1 GB、2 GB 的 XLSX 能快速导入吗？** 当前没有 XLSX 结构化数据导入 / 编辑，不承诺该能力。数据科学使用 CSV / TSV，逐记录读取，但单字段、记录、去重与分组状态仍有预算。大数据工作前请先转换为合适格式并试验数据规模。

**绘图需要 R 或 Python 吗？** 当前条形图、分类折线、直方图和散点图均为 C# / WPF，无需额外环境。数值图使用有限抽样，图中有样本说明；复杂统计和可重复科研绘图可在后续作为可选高级环境评估。

**PDF 水印都能删除吗？** 只能移除轻舟自己添加且保留恢复标记的水印。其他水印、扫描图内水印不自动删除。加密、签名和交互表单 PDF 暂不处理。

**PDF 预览显示原页面吗？** 0.6 水印窗口只预览水印位置和样式；0.7 候选可通过 Windows 缩略图处理器或另外配置的 MuPDF 读取真实首页，不可用时说明原因。导出后仍需用 PDF 阅读器检查实际效果。尺寸归一化与拆分合并也不等于完整 PDF 编辑器，详见[PDF 与组件](components.md)。

**会修改或上传原文件吗？** 图片、PDF、数据和压缩结果默认另存，不覆盖已有结果。重命名会改变文件名；批量改名有独立恢复记录。OCR 在本机运行，主动点击翻译才向所选服务发送结果框中的文字，不发送截图。0.6 使用 MyMemory，0.7 候选增加 LibreTranslate 兼容服务配置，详见[截图与翻译](capture.md)。流程文件可能含筛选词，改名记录含完整路径，分享前需检查。

**添加软件会改变 Windows 默认吗？** 不会。Windows 默认始终保留，自定义 EXE 另外添加。次数只用于推荐；轻舟内优先需要明确设置。追加 Windows 推荐不会写入 UserChoice，原生菜单刷新及排序由系统控制。

**花屿为何没有立即出现？F2 有什么变化？** 自动花屿等待系统双击窗口，避免干扰双击打开。0.6 常驻进程处理 F2 时独立取得当前文件，不等待花屿或缩略图；进程未运行时无法接管按键。

**支持密码、分卷、RAR 创建吗？** 暂不支持。普通 7z / RAR 解压需要可选 7-Zip；内置 ZIP 无需引擎。高级解压有一万项、512 MiB 声明数据预算，并拒绝链接和不安全路径。

**为什么工作台要排队？** 重任务使用全局单槽，避免多文件同时处理导致资源叠加。取消前保留已完成结果，原文件不覆盖。OCR 等待长任务的体验仍是后续优化点。

**如何卸载或更新？** 见[使用说明](usage.md#更新与移除)。0.6 没有控制面板卸载项；0.7 候选安装版已加入当前用户、按版本的标准卸载项，卸载保留个人设置与可选组件。换路径前关闭旧启动项，退出旧版，再运行新版。当前安装器未代码签名，文件校验见[下载说明](../releases/README.md)。

**可以直接下载演示数据吗？** 可以。[五分钟示例](../examples/README.md)提供原始 CSV、实际清理结果、流程 JSON、地区汇总和导出图，可按步骤复现；[分类图片墙](../screenshots/README.md)直接展示所有 62 张功能图。

**这些截图能证明什么？** 图库展示合成数据的真实界面。实际文件导出、外部引擎、独立渲染及尚未实机覆盖的场景另见[验证范围](validation.md)，不会把界面截图当成所有功能已通过的证据。
