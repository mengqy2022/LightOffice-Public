# 更新记录

## 0.6.0 — 2026-11-11

### 文件与桌面

- F2 改名独立读取当前选择，首屏先显示文件信息、后台补预览。
- Windows 默认打开入口常驻；读取系统推荐，追加当前用户的推荐程序，保留原关联。
- 各花屿有会话置顶按钮；全局默认与工作台置顶继续独立。
- 分类操作区由三项扩展为最多九项，常用优先，统一叶片轮廓与花瓣配色。
- 窗口品牌图标、关于页、当前用户安装器和便携包。

### 新工作台能力

- CSV / TSV 流程 JSON 保存 / 载入，严格列结构复核。
- 数值直方图与有限抽样散点图，固定种子、明确样本说明、PNG 另存。
- 批量改名预览、冲突检测、哈希恢复记录与花屿路径同步。
- 图片 / PDF 文字水印、批量另存，移除带轻舟恢复标记的 PDF 水印。
- 可选 7-Zip 的普通 7z / RAR 安全解压，明确拒绝加密、分卷、链接及超限输入。
- 可配置截图、识别与翻译快捷键；冲突提示，结果继续在 GUI 内展示。

### 验证和边界

专项覆盖与实机未验证项见[验证说明](validation.md)。大 XLSX 编辑、通用 PDF 去水印、密码 / 分卷解压、离线翻译模型不属于该版本能力。
