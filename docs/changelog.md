# 更新记录

## 0.7.4.0 截图画笔与交互优化 — 2026-11-12

- 截图新增自由画笔：两主题均在「框选」右侧，六色、2 / 3 / 6 物理像素粗细、整笔撤销；绘制中 Esc 取消本笔。
- Enter 复制包含标注的截图并关闭，随后在聊天框或 APP 按 Ctrl+V，无需创建图片文件；Ctrl+S 仍可另存 PNG。文字编辑、语言选择与未完成笔画避免误触；复制失败保留选区和标注。
- 窗口按实际工作区和 DPI 限制尺寸；小屏低于设计尺寸时滚动，大屏恢复；截图工具栏自动换行与滚动。
- 首次四步引导、六行 CSV 的真实筛选 / 另存练习、按使用习惯提供且可关闭的紧凑快捷键提示。
- 单文件改名及快捷键 / 翻译设置保存成功后关闭；失败保留。文件结果工作台继续保留供检查和连续处理。
- PDF 入口统一为「移除已添加水印」，仅支持本软件添加且保留恢复标记的水印；关于页补充 Mengqy、Codex、版本、博客及邮箱。
- 公开 README 增加简体中文 / English 导航，补充画笔与小屏图；软件和安装器界面目前仍为简体中文。
- 保留自定义目录、许可说明、独立卸载程序与适度保护，无新增运行 DLL 或大型引擎。当前程序及安装器未签名。
- 按构建区分专项与人工证据，未把最新真实画笔 / APP 粘贴或长期恢复记为已验收；见[验证说明](validation.md)。

## 0.7.3.0 安装体验升级 — 2026-11-12

- 中文安装向导：欢迎、许可、安装说明、目录选择、附加选项、准备、进度和完成。

- 自启默认关闭；卸载只清理指向本版本的自启项；通用快捷方式识别已登记的自定义目录。
- 运行功能沿用 0.7.2.0，仅更新主程序版本元数据，保留混淆，无新增运行 DLL。
- 操作见[安装指南](installation.md)，范围见[验证说明](validation.md)。本版仍未代码签名。

## 0.6.0 — 2026-11-11

### 文件与桌面

- F2 改名独立读取当前选择，首屏先显示文件信息、后台补预览。
- Windows 默认打开入口常驻；读取系统推荐，追加当前用户的推荐程序，保留原关联。
- 各花屿有会话置顶按钮；全局默认与工作台置顶继续独立。
- 分类操作区由三项扩展为最多九项，常用优先，统一叶片轮廓与花瓣配色。
- 窗口品牌图标、关于页、当前用户安装器和便携包。

### 新工作台能力

- CSV / TSV 流程 JSON 保存 / 载入，严格列结构复核。
- 数值直方图与有限抽样散点图，固定种子、明确样本说明、PNG 另存。
- 批量改名预览、冲突检测、哈希恢复记录与花屿路径同步。
- 图片 / PDF 文字水印、批量另存，移除带轻舟恢复标记的 PDF 水印。
- 可选 7-Zip 的普通 7z / RAR 安全解压，明确拒绝加密、分卷、链接及超限输入。
- 可配置截图、识别与翻译快捷键；冲突提示，结果继续在 GUI 内展示。

### 验证和边界

专项覆盖与实机未验证项见[验证说明](validation.md)。大 XLSX 编辑、通用 PDF 去水印、密码 / 分卷解压、离线翻译模型不属于该版本能力。
