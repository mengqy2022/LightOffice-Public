## 文件操作

图片、PDF、CSV / TSV、ZIP 的内置处理在本机执行，结果另存新文件或目录。单文件 / 批量改名会真实改变名称；恢复记录保存完整源 / 目标路径和内容哈希。数据流程不嵌入原始行与源文件路径，但列名、输出名称和筛选词仍可能是业务信息。

复制路径会将完整路径写入剪贴板；复制截图或译文也会写入对应内容。使用系统剪贴板历史 / 云同步或其他剪贴板工具时，相关行为由系统和这些工具决定。未保存的直接贴图关闭后不应视为已归档文件。

## OCR 与在线翻译

OCR 使用本机 Windows 能力，不为识别向翻译服务上传截图。用户主动点击翻译时，发送结果框中的文字到所选服务；0.6 为 MyMemory，0.7 系列另支持 LibreTranslate 兼容服务。图像不作为翻译请求正文上传。

翻译服务的「测试连接」也会向服务发送测试文字。不要将敏感内容交给未经确认的第三方端点；自托管服务的日志和保留策略由部署者负责。API Key 在当前 Windows 用户下通过 DPAPI 加密保存，这不表示该机器上的所有配置都已加密，也不保证可跨用户 / 机器直接迁移。

## 可选程序与 Windows

调用办公、压缩、PDF 预览或文件打开程序时，会向所选本机程序传递文件；这些程序可能有自己的联网、日志或云功能。追加系统推荐会写入当前用户的推荐登记，不修改 Windows 默认 UserChoice。登录自启是当前用户的启动登记，切换路径或卸载前应主动关闭。

## 分享示例和问题反馈

维护者反馈渠道为[轻舟博客评论](https://www.mqymmb.com/posts/lightoffice/#license-note)及邮箱 **15877464851@163.com**。评论和 Issue 通常公开；邮件由用户主动发送，不将其视为匿名渠道。关于页仅打开浏览器或系统邮件草稿，不自动提交反馈。

0.7.4 的截图按需提示仅在现有设置中保存最近十次菜单 / 快捷键触发标记、显示次数、上次提示时间及关闭选择，不记录画面或文字，不上传。可在「截图快捷键」关闭，见[提示说明](getting-started.md#经常用截图再轻轻提醒一次)。

公开库的示例均为合成内容。演示中的路径已隐藏或显式替换；翻译服务地址使用保留示例域名，不包含密钥。步骤动图由真实界面图片组成，不是私人桌面录屏。

提交 Issue 前移除原始业务数据、完整路径、用户名、API Key 和恢复记录。最有帮助的是一个能复现问题的最小合成文件及操作步骤；如果只能用私人文件复现，先描述现象，不要直接上传公开 Issue。
