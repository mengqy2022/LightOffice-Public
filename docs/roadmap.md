# 后续优化方向

0.6 已提供文件快捷入口、常用处理、数据流程、基础绘图与可选引擎。[0.7 系列](preview-0.7.md)已完成可选圆弧主题、工作台同步换色、启动修复、PDF 真实首页预览、翻译服务配置和标准卸载的实现，现已随 0.7.2 正式发布。接下来优先基于实测继续收敛：

1. **桌面真实环境验收**：不同 Windows 版本、登录自启、休眠恢复、Explorer 重启、多屏 DPI 切换；记录快速 F2、双击与拖动的耗时和误触率。
2. **长期资源基准**：空闲、反复开关图片 / 数据 / 截图窗口、引擎退出与临时文件清理；根据测量决定 OCR 是否需要单独但有预算的交互通道。
3. **交付完善**：按版本卸载已通过当前安装包的隔离安装 / 卸载和载荷验证，继续完成干净系统的安装 / 卸载与旧版回退矩阵、代码签名和更新流程；维护组件包版本及校验元数据。
4. **PDF 实用性**：已有真实首页预览继续验证不同系统缩略图处理器与 MuPDF 配置；后续评估页码 / 旋转操作及不同 CropBox / 透明组文档回归，不承诺任意扫描水印无损移除。
5. **数据高级能力**：在独立可选进程中验证 Parquet / DuckDB 和大数据基准，再决定连接、透视及更多统计图；基础包继续不强制安装 Python / R。
6. **截图翻译服务**：已有 MyMemory / LibreTranslate 兼容服务设置，继续做实际网络、超时、额度、凭据与不同返回格式验证，再考虑更多语言；始终在软件内显示结果。
7. **公开展示维护**：当前已补齐全功能入口、69 张界面图、六个任务教程、三幅实际效果对比、三个步骤动图和可复现示例；后续每次正式发布同步图片版本、下载资产和测试边界，继续补充真实操作短视频。步骤图轮播不冒充连续录屏。

顺序可能根据问题反馈调整；这里只描述方向，不是已经完成的功能或承诺日期。
