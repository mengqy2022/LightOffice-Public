所有图片来自合成测试文件的真实界面，截图功能在内存中替换为合成背景后才制作图库。没有将用户实际文件、私人屏幕或源代码作为产品演示发布。关于页的开发路径已显式遮盖。

## 本机真实输入与启动采样

0.6.0.0 本机通过 41 项鼠标 / 键盘输入检查：资源管理器和桌面在单击后约 50 / 100 / 200 / 500 毫秒发出 F2，核对当前文件名、输入焦点与 Esc 取消，覆盖保留花屿。测试只使用新建的合成文件，并检查取消后文件内容与名称保留。时间是本机注入测试，不是所有机器的延迟保证。

一次新进程、系统缓存已热的启动采样：首份状态约 492 ms；20秒空闲时工作集约77.8 MiB、私有字节约92.0 MiB、581句柄。没有强制GC或裁剪工作集，不包括可选引擎。它不是冷磁盘启动、长期峰值或所有文件场景的内存上限。

## 资源测量如何理解

重复打开 / 关闭数据和关于窗口十二轮，活窗口数量回到基线；记录工作集、私有字节和句柄，不强制 GC 或裁剪工作集。该短测仍存在内存增长，不能据此宣称长期无泄漏或稳定内存上限。包体也不等于进程工作集；后续需对真实空闲、图片和引擎子进程分别长期采样。

## 尚未覆盖的真实环境

- 未通过登出或重启用户电脑来验收真实登录自启。
- 未通过强制重启 Explorer 或休眠用户电脑来验收恢复。
- 几何测试覆盖 100 / 125 / 150 / 200% 缩放与不同工作区，不等同于真实多显示器 DPI 切换。
- 系统推荐枚举通过不代表每个 Windows 版本的原生菜单顺序和刷新时间相同；商店应用及本地全部应用组合仍需用户环境反馈。
- 样本文档验证不能保证所有 PDF、字体、Office 版式或 RAR 编码方式都支持。

安装器载荷与发行清单另做逐文件 SHA-256 校验；所有可下载文件的哈希以 Release 资产中的 `.sha256` 为准。
