# 安装、升级与卸载

[正式下载](../releases/README.md) · [三分钟上手](quickstart.md) · [版本对照](versions.md)

0.7.3.0 将简易安装窗口升级为中文 Inno Setup 向导。安装框架只用于制作安装包，不作为常驻引擎运行；基础包仍不包含办公套件、压缩软件或 Python / R。

## 安装前

需要 Windows 10 / 11 和 .NET Framework 4.8。先保存工作台结果并从托盘退出旧版；安装器不会强制终止轻舟，也不会自动下载运行环境。当前发行仍未代码签名，请从官方 Release 下载，并按[校验说明](../releases/README.md)核对 SHA-256。

## 安装向导

1. **欢迎。** 显示产品版本、当前用户安装方式和卸载入口。
2. **许可。** 阅读中文摘要及正式使用条款，接受后继续；旧 MIT 授权与第三方许可保留。
3. **安装说明。** 说明系统要求、可选组件、OCR / 在线翻译的数据处理以及卸载保留范围。
4. **安装位置。** 默认是当前用户的 `%LocalAppData%\Programs\LightOffice\0.7.4.0`，也可以浏览选择其他可写的专用文件夹。界面显示所需磁盘空间。
5. **附加选项。** 可选择桌面快捷方式；登录自启默认不选。开始菜单提供版本入口和卸载入口。
6. **准备与进度。** 核对位置和选项，查看解包 / 文件复制进度。安装中发生文件错误时，框架提供失败处理和回滚。
7. **完成。** 可主动勾选启动轻舟；不会在静默部署或未勾选时自动启动。

安装器不申请管理员权限。受保护目录不可写时，请选择自己的可写目录。不要选择磁盘根目录、桌面或个人文档根目录；已有其他内容的文件夹会被拒绝，以免覆盖数据。同版本已安装时应在原位置重装；要更换目录，先卸载该版本。不同版本使用独立目录，不覆盖旧版。

## 卸载的三个入口

| 入口 | 操作 |
|---|---|
| Windows 应用列表 | 设置 → 应用 → 已安装的应用 → 轻舟 LightOffice 对应版本 → 卸载 |
| 开始菜单 | 轻舟 LightOffice → 卸载轻舟对应版本 |
| 安装目录 | 直接双击 `unins000.exe`，同目录 `unins000.dat` 也需保留 |

卸载前从托盘退出轻舟。默认保留个人设置、可选组件和其他版本；卸载向导可单独勾选“同时删除个人设置”，此选项会影响共享设置的所有版本，但不会删除可选组件。

卸载按安装日志删除本版本登记的文件，不递归清空整个安装目录。用户后来放入目录的结果等新增文件会保留；但不要修改或用个人文件替换程序自带的同名文件，这些文件属于安装清单。原始文件、导出结果和改名恢复记录仍应自行备份。

仅当登录自启仍指向被卸载的这个版本时，卸载器才移除该启动项；指向其他版本的登记保留。通用开始菜单快捷方式会查找剩余已登记版本并回退，支持新安装器登记的自定义路径。

## 旧版与便携版

0.7.2.0 及更早的安装器行为不会被新包追溯修改，特别是旧卸载器只认识固定目录。建议先卸载不再需要的旧版，再安装到自定义位置；若旧卸载器重置通用快捷方式，使用新版本专属快捷方式，或在原目录重装新版本恢复入口。

便携 ZIP 不登记卸载项，也不生成 `unins000.exe`。退出轻舟后移除便携目录即可；如果曾开启登录自启，先在该版本关闭它。个人设置和另外配置的外部引擎保留。

## 日志与验证边界

安装器默认在用户临时目录生成 `Setup Log … .txt`。日志可能包含用户名、路径和命令行，提交反馈前先脱敏。可以使用 Inno Setup 标准 `/LOG="完整路径"` 参数指定安装 / 卸载日志。

本轮完成实际安装器静默集成专项：自定义中文 / 空格 / 单引号路径、默认路径、逐文件哈希、安装失败回滚、登记 / 快捷方式、自启及卸载保留范围。测试采用独立目录和专用测试登记，不运行产品或注入键鼠；这不等于所有 Windows 环境、DPI、权限和安全软件组合均已验收。
