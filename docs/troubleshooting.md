# 安装与故障排查

[上手教程](quickstart.md) · [版本差异](versions.md) · [反馈问题](https://github.com/mengqy2022/LightOffice-Public/issues/new/choose)

优先记录版本、文件类型和具体提示，再按对应步骤检查。先用合成样例验证；不要公开私人文件、API Key、完整恢复记录或带敏感路径的日志。

## 启动后没有看到窗口

1. 展开任务栏右侧隐藏图标，确认轻舟是否在托盘运行。关闭花屿不等于退出进程。
2. 0.6 正式版存在首次手动启动只进入后台的情况，先选中文件，通过托盘入口操作。0.7.2 已包含首次手动启动显示修复，重复启动用于唤起实例；建议从正式 Release 更新。
3. 登录自启使用后台模式，不主动显示花屿；到桌面 / 资源管理器选一个普通文件再检查。
4. 若程序报缺少组件，确认保留同目录 DLL 与配置，检查系统 .NET Framework 4.8；从原始 ZIP 完整解压到新目录重试。
5. 如被安全软件隔离，先核对来源与 SHA-256，查看实际拦截原因。当前未签名，不建议为运行软件而关闭全局安全防护。

## 单击文件后花屿没有出现

在「桌面与自动展开」依次检查总开关、十分钟暂停及当前目录排除。自动展开等待双击判定；不应以立即出现作为判断标准。尝试新建目录里的普通本地文件；仍失败时使用「重新连接监听」，记录是在桌面还是资源管理器、Windows 版本及是否多标签页。系统特殊命名空间和不同应用的文件列表不能视为全部支持。

## F2 仍进入系统改名

先检查轻舟进程是否运行、当前文件是否在支持的桌面 / 资源管理器位置选中。进程未运行时无法接管 F2。不要连续输入来试探，以免文字进入系统名称框；按 Esc 取消后再检查。已运行仍复现时记录单击到 F2 的大致间隔、版本与位置，使用测试副本反馈。

## 打开方式没有立即对齐

1. Windows 默认入口应保留；先检查是否曾主动设过「轻舟内优先」，需要时切回「跟随 Windows」。
2. 关闭并重新打开轻舟的打开方式面板，再检查系统推荐。软件被卸载或 EXE 被移动时，删除失效的本地项后重新添加。
3. 「加入系统推荐」只追加候选；原生菜单顺序 / 缓存由 Windows 控制，不保证立刻出现或完全同序。
4. 系统默认需要通过 Windows 设置修改，轻舟不会强行写入 UserChoice。商店应用走系统处理程序，不应随意寻找或修改其受保护安装目录。

## 紧凑、大小或主题看起来没有变化

区分花屿尺寸与独立工作台尺寸：紧凑 / 小巧 / 标准 / 清晰主要调整花屿，不能当作所有窗口的缩放功能。经典 / 圆弧主题选项已在 0.7.2 正式版提供，旧版 0.6 没有该菜单。出现「仅本次生效」时检查设置文件是否被占用，解除占用后重新选择；不要在运行时手工删除设置。

## OCR 为空或准确率低

确认选择了对应 Windows OCR 语言能力；在 Windows 语言设置检查所需语言，某些精简系统可能缺少 OCR 组件。先用清晰、水平、无标注遮挡的少量文字测试；缩小过大选区，避免超过系统识别尺寸或截图预算。识别后修正文字再翻译。没有识别能力时，配置翻译服务也不能替代 OCR。

## 翻译失败或一直等待

检查结果框中是否有正确原文、网络是否可用、是否超过长度或服务额度；保留错误提示。取消后原文应保留。0.6 使用 MyMemory；0.7 系列可配置 LibreTranslate 兼容地址与密钥。`translate.example.org` 只是文档示例，不是可用服务。自托管地址需要正确的 `/translate` 路径，远程要求 HTTPS；不要把 API Key 放入公开反馈。

## Office 转换提示没有可用引擎

图片、PDF、ZIP、CSV 基础功能不依赖 Office；DOCX / XLSX / PPTX 转 PDF 需要本机 Office 或 LibreOffice。到「可选组件」检查启用状态并选择已有程序，确认它能独立运行。配套离线 ZIP 有专用结构，不能把官方 MSI / EXE 改后缀后导入。版式、字体与分页转换后仍需复核。

## PDF 无法处理或预览为空

加密、数字签名、交互表单和特殊结构可能不支持；非 A4 页带批注或链接时尺寸转换可能拒绝。先用[公开样例](../examples/pdf/mixed-pages.pdf)核对基础功能，不要破坏原件。0.6 水印预览只有位置示意；0.7 系列真实首页依赖 Windows PDF 缩略图处理器或已有 MuPDF。预览不可用与 PDF 输出是否成功要分别核对。

## 数据乱码、日期报错或流程载入失败

自动 / BOM 无 BOM 时按 UTF-8；乱码时按源文件选择 GB18030、Big5 等编码。日期列选择实际格式，筛选日期统一填 `yyyy-MM-dd`。流程要求列名与顺序、编码匹配；示例流程应载入原始 `sales.csv`，不要载入已经改过列名的 `cleaned.csv`。另存目标已存在、被占用或状态预算超限时，选择新文件并检查提示。XLSX 不是当前数据科学输入格式。

## 改名或导出中途失败

单文件输出失败不应发布半成品；批量操作已完成项目可能保留。先查看状态和输出目录，不要反复覆盖。改名恢复依赖内容哈希及原名称未被占用；解除占用并保留记录，再按当前状态恢复。已经外部修改的文件不要强行套用旧记录。
